# Citrix NetScaler ADC / WAF

Schema: NetScaler 14.1. These scenarios represent documented event families with synthetic lab identities.

Formats: native, cef. Representative synthetic wire format; live vendor parser validation required.

Field reference: [NetScaler 14.1](https://docs.netscaler.com/en-us/citrix-adc/current-release/application-firewall/logs.html).

Catalog coverage: access authentication waf administration. Existing scenarios and polling mocks are retained. CSV rows omit file headers. Optional/trailing vendor fields are omitted; fixtures are structural examples, not a guarantee for every firmware/parser version. CEF uses standard src/dst/spt/dpt/act/suser/dvc/dvchost fields. XML uses the Windows Event namespace.
